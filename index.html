Subway countdown clock

A board of lights in my apartment that knows when my train is coming.

It shows the next R and M trains from 63 Dr–Rego Park toward Manhattan, and once a minute the arrivals slide away and the time slides in. On Friday evenings, Saturdays and holidays it also shows candle-lighting and havdalah times. It was my first hardware project: I'd never touched a Raspberry Pi before this.

Receipt tracker

Photograph a receipt, then ask about your spending in plain English.

An AI agent reads each receipt photo into a database, line by line. Then you can ask it things like "how much did we spend on groceries in August?" and get an answer. I built it with a collaborator as a web app and I'm now turning it into a phone app that a whole household can sign into.

Status
Expanding · mobile, multi-user
How it works
Claude vision reads the photo; line items go to Supabase; questions are answered over that table
Built with

  • Express
  • Claude API
  • Supabase
